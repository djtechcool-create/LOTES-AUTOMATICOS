CONTEXTO DEL PROYECTO
--------------------------------------------------------------------------------

Proyecto: LOTES-AUTOMATICOS
Repo: https://github.com/djtechcool-create/LOTES-AUTOMATICOS
Objetivo: Automatizar la carga de egresos en DALI (sistema de logistica web).

El usuario procesa 40-50 referencias diarias en DALI. El proceso manual toma
3-4 horas. Con esta app deberia tomar 20-30 minutos.

STACK:
- Python 3 + Flask (interfaz web local)
- Selenium + Chrome (automatizacion web)
- pandas + openpyxl (Excel)
- fuzzywuzzy (matching de nombres)

CREDENCIALES DALI:
- URL: https://sistemapae.nutri.com.ec/
- Usuario: azapata
- Password: 1753112158

ARCHIVOS PRINCIPALES:
- app.py -> Servidor Flask, orquesta todo el flujo
- automator/dali_client.py -> Cliente Selenium, login + JSON APIs
- automator/excel_reader.py -> Lee Excel del dia
- automator/matcher.py -> Matching fuzzy Excel vs DALI
- automator/report.py -> Genera reportes .txt
- mapping.json -> Cache de matches exitosos (en .gitignore, local)
- templates/index.html -> Interfaz web oscura con Bootstrap
- AGENTS.md -> Documentacion completa del proyecto

FLUJO DE PROCESAMIENTO:
1. Login a DALI via Selenium (requests.Session no sirve, necesita cookies JS)
2. Leer Excel del dia, filtrar solo tipo="salida"
3. Para cada referencia del Excel:
   a. Buscar egreso en DALI cuya HOJA RUTA termina en esa referencia
   b. Cargar productos del egreso (JSON 2094)
   c. Para cada producto: hacer match fuzzy con el Excel
   d. Asignar lote + cantidad (JSON 2096)
   e. Procesar/finalizar egreso (JSON 2099)
4. Generar reporte con los resultados

JSON ENDPOINTS DE DALI (todos POST a /?option=json con parametro "json"):
- 2093: Lista egresos generados
- 2091: Carga datos de un egreso (param: mbocodigo)
- 2094: Carga productos de un egreso (param: mbocodigo)
- 2092: Carga lotes disponibles (param: dmbcodigo)
- 2095: Verifica lotes asignados (param: mbocodigo, pgecodigo, pescodigo)
- 2096: Asigna lote a producto (param: dmborigen, dmbdestino, ilocodigo, cantidad)
- 2097: Elimina lote asignado (param: dmborigen, dmbdestino)
- 2099: Procesa/finaliza egreso (param: mbocodigo)

VARIABLE UI: Es un JavaScript global (ahora valor 43) que se establece despues
del login. Se necesita para todas las llamadas JSON. El dali_client.py lo obtiene
ejecutando JS en el navegador.

IMPORTANTES:
- FlexiGrid de egresos solo muestra los ultimos ~10. Hay que buscar por HR usando
  flexOptions({qtype:'HOJ', query:ref}) + flexReload()
- Usar SALDO del JSON 2094, NO la cantidad del Excel
- Los nombres NO coinciden exactamente entre Excel y DALI (usar fuzzy matching)
- El mapping.json guarda matches exitosos para reusar
- Si asignar_lote falla (stock insuficiente), NO reintentar otro lote automaticamente
- Reportar al usuario cuales fallaron para que el decida

ESTADOS DEL REPORTE:
- ok: Egreso asignado y procesado correctamente
- skip: Ya estaba procesado, se salto
- error: Algun producto fallo (sin match, sin lote, asignacion fallida)
- review: Todos los productos con SALDO=0 (ya asignados en sesion anterior,
  requieren solo que el usuario revise y ejecute "Procesar" en DALI)
